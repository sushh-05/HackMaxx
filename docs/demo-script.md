# Demo Script (≤165s)

A tight, rehearsed walkthrough that makes AWS usage impossible to miss.

---

## 1. Hook — 15s

> *"I waste 5 hours a week hunting hackathons across Devpost, Unstop, and Devfolio. HackMaxx tells me where my project fits best."*

---

## 2. AWS Proof — 30s

Show the console while talking:

- DynamoDB table with embeddings visible.
- Lambda logs invoking Bedrock.
- API Gateway URL.

> **Pro tip:** Record a 10s console clip on Day 1 as backup insurance.

---

## 3. Live Flow — 90s

Navigate end-to-end:

1. **Explore** — browse the hackathon list.
2. **Maxx My Project** — enter a CP tutor project (Bedrock + Lambda).
3. **Click Find** — cards stream in with Worth Score, *why it matches*, and reuse badge.
4. **Strategy Panel** — *"Submit to these 3 in the next 10 days."*

---

## 4. Impact + Learning — 30s

> *"Saves 4–5 hours, focuses on high-ROI events. Learned Bedrock agents, DynamoDB vectors, and serverless RAG on AWS."*

---

## Tips

- Pre-seed the database.
- Hardcode one great example to avoid dead air.
- Keep the network tab hidden.
- Record the console clip on Day 1 — it's your safety net.
