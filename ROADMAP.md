# HackMaxx — Roadmap

Shipped in the MVP:

- **Live hackathon index** — Devpost, Devfolio, Unstop, MLH, unified into one watchlist with worth-ranked sorting.
- **Maxx engine** — paste a project, get semantic Worth Scores + an EV-maximizing submission plan in deadline order.
- **Portfolio positions** — save projects, re-Maxx when the tape moves.
- **Timeline Gantt, pin ticker, compare view, ⌘K palette** — the whole terminal-grade workflow.

## Next

1. **Import-any-repo onboarding** — point HackMaxx at a GitHub repo (Composio auth already wired); it extracts stack + README into a Maxx run automatically. Drop-in `GOAL.md` support: paste a goals file into your repo and HackMaxx treats it as the project brief.
2. **Deadline alerts** — watch a position, get pinged at 7d / 3d / 24h before each planned submission closes.
3. **Live catalog refresh** — Tinyfish-powered crawl of the four platforms on a schedule, replacing the static index.
4. **Win-rate feedback loop** — record outcomes, retrain the P(win) curve so EV numbers get sharper every season.
5. **Team portfolios** — share a watchlist + plan across a hackathon team.

## Later

- Embeddable "Maxxed" badge for project READMEs (worth score + EV, live).
- Platform auto-submit drafts (Devpost/Devfolio APIs where available).
